# Runtime Signal UX Experiment

Date: 2026-05-26

Status: Accepted for isolated experiment only

## Context

The runtime signal mapping experiment proved that `metrics.current.v1` responses can be interpreted into simple runtime labels, glyphs, reasons, and CSS tones inside the isolated Electron spike.

The next uncertainty is whether those signals are useful, readable, and low-noise enough to inform future Kamay Buddy companion expression.

## Decision

Allow signal UX refinement only inside the existing isolated Electron experiment.

The experiment may add priority, persistence, visual weight, and attention-style metadata to signal output. It may test CSS-only opacity, glow, pulse, badge, and label hierarchy.

This does not approve a pet/avatar system, animation framework, personality, dialogue, lore, memory, AI-agent behavior, durable product UI, or runtime selection.

## Consequences

- The telemetry/service backbone remains unchanged and authoritative.
- Runtime surfaces still consume only the versioned local service contract.
- Signal UX findings may inform future companion design, but they are not final vocabulary or product behavior.
- Any future promotion into Kamay Buddy requires a separate decision after runtime and companion direction are clearer.
